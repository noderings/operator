# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report security issues privately by emailing the maintainers through GitHub:

1. Open [https://github.com/noderings/operator/security/advisories/new](https://github.com/noderings/operator/security/advisories/new), or
2. Use [GitHub private vulnerability reporting](https://github.com/noderings/operator/security/advisories) if enabled for this repository.

Include:

- A description of the issue and potential impact
- Steps to reproduce
- Affected versions or components (operator, Helm chart, CRDs)

We aim to acknowledge reports within a few business days and will coordinate disclosure and fixes with you.
